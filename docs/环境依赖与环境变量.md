# AnnoMerge 环境依赖与环境变量

AnnoMerge 的外部工具依赖通过 **src/annomerge/deps.py** 的依赖注册表统一解析。
每个依赖按以下优先级解析：

1. **环境变量**（短名，指向安装目录或直接指向可执行文件均可）
2. **PATH 回退**（source env.sh 或 conda 环境照常工作）

## 依赖与环境变量对照表

| 依赖 | 环境变量 | 形态 | 说明 |
|---|---|---|---|
| hisat2 + hisat2-build | `HISAT2` / `HISAT2_HOME` | 目录或文件 | 目录时探测 `<dir>/<exe>` 和 `<dir>/bin/<exe>` |
| samtools | `SAMTOOLS` / `SAMTOOLS_HOME` | 目录或文件 | |
| stringtie | `STRINGTIE` / `STRINGTIE_HOME` | 目录或文件 | |
| gffread | `GFFREAD` / `GFFREAD_HOME` | 目录或文件 | gffclib 包 |
| gffcompare | `GFFCOMPARE` / `GFFCOMPARE_HOME` | 目录或文件 | gffclib 包 |
| diamond | `DIAMOND` / `DIAMOND_HOME` | 目录或文件 | |
| busco | `BUSCO` / `BUSCO_HOME` | 目录或文件 | 5.7.x（odb10 兼容）；版本探测自动清空 PYTHONPATH |
| miniprot | `MINIPROT` / `MINIPROT_HOME` | 目录或文件 | |
| TransDecoder | `TRANSDECODER` / `TRANSDECODER_HOME` | **目录** | 需含 `util/gtf_to_alignment_gff3.pl`；未设置时从 PATH 里的 TransDecoder.LongOrfs 推导 |
| EVM | `EVM` / `EVM_HOME` | **目录** | 需含 `EvmUtils/partition_EVM_inputs.pl` 等；无 PATH 回退，必须设置 |
| perl | `PERL` | 目录或文件 | EVM 脚本用 |
| Python 包 | PYTHONPATH / pip 环境 | — | pysam biopython numpy pandas gffutils typer jinja2 pyyaml |

## 使用示例

```bash
export EVM=/opt/EVidenceModeler
export TRANSDECODER=/opt/TransDecoder
export MINIPROT=/opt/miniprot/miniprot        # 直接指可执行文件也行
export HISAT2=/opt/hisat2-2.2.1
annomerge merge -c                             # 检查全部依赖后退出
```

## 依赖检查

```bash
python3 -m annomerge.cli merge -c      # 或 evaluate -c
```

输出每个依赖的状态、实测版本、解析来源（env 变量名 / PATH）及安装提示；
全部通过时退出码 0，有缺失时退出码 3。

## 数据资产

- BUSCO lineage 目录仍通过 `--busco <path>` 参数传入（offline 模式）。
- 报告模块 matplotlib SVG 用 Noto Sans CJK SC（pod 内置字体，无需配置）。

## 设计要点

- env 值为**目录**时探测 `<dir>/<exe>` 与 `<dir>/bin/<exe>`；为**文件**时直接采用（多 exe 依赖组要求文件名匹配）。
- env 指向坏目录时报错会列出期望的 marker 文件（如 `EvmUtils/partition_EVM_inputs.pl`），不会静默回退造成"用了错的安装"。
- utils.which 与各模块零改动：注册表在 utils.which 内部分发，调用点无感知。
