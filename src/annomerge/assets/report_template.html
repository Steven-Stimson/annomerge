2.4 Scoring

P = w_r·R_s + w_h·H_s + w_b·B_s + w_o·O_s   (default w_r=0.45, w_h=0.25, w_b=0.10, w_o=0.20)

R_s bundles the RNA evidence: splice-junction support, exon precision, single-exon bias, and the Gold-set protein match (GoldMatch, w=0.25 within R_s). H_s is pure homolog evidence; only when the referee protein set is smaller than --hs-referee-min (default 1000) does the Gold set rescue H_s instead (mixed at --hs-gold-weight), never counted in both.

H_s is structure-aware: a predicted protein counts only when it has a full-length referee match AND is free of chimeric/split anomalies (both criteria derive from the same miniprot hits). Missing sub-blocks are skipped and the remaining weights renormalized; with --weight-mode adaptive the B_s / O_s weights are additionally scaled by their informative coverage (the fraction of proteins the database actually gave a verdict on).
